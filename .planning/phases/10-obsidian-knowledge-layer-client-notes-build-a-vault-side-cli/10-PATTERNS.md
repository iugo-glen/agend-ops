**What to copy from instead:**

1. **Repo conventions for input validation** — mirror `scripts/validate-data.sh`'s "validate before consume" stance in Python:

   ```bash
   validate_jsonl() {
     local file="$1"
     local label="$2"
   ```

### `mac/install-daemon.sh` (utility, installer)

**Analog:** `scripts/build-dashboard-data.sh` for the shell-script idempotency style; conceptually similar to `scripts/push-and-sync.sh`'s "do one thing well" approach.

**Idempotency pattern to copy** — `build-dashboard-data.sh` checks `[ -s "$file" ]` before each operation; the daemon installer should similarly check before each step:

```bash
#!/usr/bin/env bash
set -euo pipefail
REPO_ROOT="$(cd "$(dirname "$0")/.." && pwd)"
PLIST_SRC="$REPO_ROOT/mac/com.agend.vault-sync.plist"
PLIST_DEST="$HOME/Library/LaunchAgents/com.agend.vault-sync.plist"

# 1. fswatch present?
if ! command -v fswatch >/dev/null 2>&1; then
  echo "Installing fswatch via Homebrew..."
  brew install fswatch
fi

# 2. plist installed?
if [ ! -f "$PLIST_DEST" ] || ! cmp -s "$PLIST_SRC" "$PLIST_DEST"; then
  cp "$PLIST_SRC" "$PLIST_DEST"
  echo "Installed plist: $PLIST_DEST"
fi

# 3. unload-then-load (idempotent reload)
launchctl unload "$PLIST_DEST" 2>/dev/null || true
launchctl load -w "$PLIST_DEST"
echo "LaunchAgent loaded."
```

**The `2>/dev/null || true` idiom** matches `scripts/push-and-sync.sh` line 13's defensive pattern:
```bash
... git checkout -- data/queue/ 2>/dev/null; git clean -f data/queue/ 2>/dev/null; ...
```

- `process-queue.md` line 41 (invoice update)
- `process-queue.md` line 57 (todo update)
- `process-queue.md` line 74 (task update)
- `task.md` and `invoice.md` — same `.tmp + mv` for record updates

**Concrete excerpt** (`process-queue.md` line 41):
```bash
jq "if .id == \"$INV_ID\" then .status = \"paid\" | .completed_at = \"$NOW\" else . end" \
  data/invoices/active.jsonl | jq -c '.' > data/invoices/active.jsonl.tmp \
  && mv data/invoices/active.jsonl.tmp data/invoices/active.jsonl
```

**Apply to vault_writer.py:** This shell idiom is the conceptual ancestor of the more rigorous `tempfile.mkstemp` + `os.replace` + `os.fsync` pattern in RESEARCH.md Pattern 1. **Apply to:** All managed-section writes in `vault-build/` and (Mac-side) iCloud canonical vault.
